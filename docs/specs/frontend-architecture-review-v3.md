# Frontend Architecture Review v3

状态：已完成
基线日期：2026-08-15

## 1. 目标

在完整梳理当前 React 前端实现的基础上，将“确切缺陷”和“后续演进”分开处理：

- 能由代码路径复现、可能展示错误业务上下文或阻碍基本操作的问题，本阶段修复并测试；
- 只影响长期维护、极端规模或团队协作效率的建议，仅记录为面试中的后续优化，不继续扩大校招项目范围；
- 不修改 AI Provider、Agent Loop、工具 Schema、RAG 检索、数据库模型和服务端协议。

## 2. 已确认缺陷

### P1-1：运营工作台周期切换展示旧数据

工作台第一次加载后将 `loading` 设为 `false`，后续切换 7/14/30 天、商家或店铺时没有重新进入加载态。请求完成前，页面标题和筛选值已经变化，但指标仍来自旧上下文。

修复要求：

- 工作台数据迁移到现有 TanStack Query 管理；
- Query Key 必须包含商家、店铺和天数；
- 切换上下文时不得用新筛选标题展示旧指标；
- 最近 AI 会话继续使用独立查询，失败不得阻塞经营数据。

### P1-2：手写异步请求存在后返回覆盖

以下读取使用本地 state，较慢的旧请求可能在较快的新请求之后返回：

- 订单详情切换；
- 店铺刊登切换；
- 规则知识库商家切换；
- AI 会话的商家、搜索词、归档和分组切换。

修复要求：

- 引入轻量的“最新请求令牌”Hook；
- 只有当前最新请求可以提交数据、错误和 loading 状态；
- 关闭订单详情或切换商家时立即使旧请求失效；
- 不引入新的状态库，也不改 API 协议。

### P1-3：可点击列表缺少键盘入口

工作台最近会话、运行任务、近期成果以及 AI 会话列表依赖整行 `onClick`，无法稳定通过键盘触发。

修复要求：

- 可点击整行提供明确角色、焦点和 Enter/Space 激活行为；
- viewer 的纯展示行不得伪装成可点击元素；
- 操作菜单按钮继续阻止冒泡，避免选择会话和打开菜单同时发生。

## 3. 验收标准

| 编号 | 验收项       | 完成标准                                                   |
| ---- | ------------ | ---------------------------------------------------------- |
| AC-1 | 工作台缓存键 | 商家、店铺、7/14/30 天使用相互隔离的 Query Key             |
| AC-2 | 工作台加载   | 上下文切换期间不展示与筛选标题不一致的旧指标               |
| AC-3 | 最新请求     | 旧请求完成后不能覆盖订单、店铺、规则文档或 AI 会话的新结果 |
| AC-4 | 关闭失效     | 订单 Drawer 关闭后，未完成请求不能重新写入详情             |
| AC-5 | 商家切换     | AI 会话立即清空旧商家选择，旧搜索响应被忽略                |
| AC-6 | 键盘操作     | Enter 与 Space 可打开最近会话、任务、成果和 AI 会话        |
| AC-7 | 权限语义     | viewer 纯展示区域不获得虚假的链接或按钮语义                |
| AC-8 | 工程验证     | format、lint、typecheck、i18n、测试与生产构建通过          |
| AC-9 | 冻结边界     | AI/RAG 服务端、Prisma 与两个只读原项目无差异               |

## 4. 非缺陷与后续演进

以下内容不影响当前核心演示正确性，本阶段不实施：

- 将所有后台 CRUD 页面一次性迁移到 TanStack Query；
- 为超长 AI 会话增加虚拟列表；
- 引入 Storybook、微前端、PWA、WebSocket 或完整设计系统；
- 追求 100% 测试覆盖率；
- 为不超过 1000 行的导入预览引入 Web Worker；
- 将筛选条件全部同步到 URL；
- 接入生产级前端监控平台。

这些可以在面试中作为用户量、数据规模或团队规模增长后的演进方向，但不能描述成当前已经实现。

## 5. 完成记录

- 工作台经营数据已迁移到 TanStack Query，缓存键包含商家、店铺与周期，切换到未缓存上下文时展示加载态；
- 新增通用最新请求令牌 Hook，并接入订单详情、店铺刊登、规则文档与 AI 会话列表；AI 会话可见数据额外按商家隔离；
- 工作台最近会话、运行任务、近期成果与 AI 会话列表支持键盘聚焦，以及 Enter/Space 激活；viewer 展示行不增加交互语义；
- 新增 5 条自动化测试，覆盖请求失效、订单详情乱序响应、AI 会话跨商家乱序响应、工作台 Query Key 隔离和键盘入口；
- 根级 `verify` 通过：API 145、Web 70、Worker 1、Shared 6，共 222 条测试；生产构建最大业务页面为 AI 对话页 198.72 kB（gzip 60.95 kB）；
- 内置浏览器因无法访问命令运行环境中的临时 Vite 端口，未将本轮记为真实浏览器验收；既有 Playwright 核心旅程未改动；
- AI/RAG 服务端、Prisma、`ai-chat/` 与 `ecommerce-admin/` 均未修改。
